# Roadmap

## 0.1.0 — complete suite foundation

- Seven open-standard skills and shared Harness Engineering v1 contract.
- Deterministic scanners, validators, drift detection, and health scoring.
- Distribution-only npm installer and Claude/Codex/generic adapters.
- Fixture, trigger, workflow, installation, and platform CI coverage.
- English and Simplified Chinese documentation.

## Later candidates

These are proposals, not current capabilities:

- Signed release provenance and published package verification.
- Additional native client adapters only after official directory contracts are
  documented and tested.
- Optional schema migrations when the managed Harness format reaches v2.
