## 人工验收步骤

1. 在干净 checkout 运行 `npm test`、`npm run lint:markdown` 和
   `npm pack --dry-run --json`，核对版本、测试数与 payload。
2. 从实际 tarball 安装到隔离目录，运行 version/install/doctor，再重复用户修改后的
   update/uninstall 冲突保护流程。
3. 打开 GitHub PR 渲染后的中英文 README，检查 hero、徽章、表格、代码块、语言切换与
   窄屏可读性。
4. 查看最终 commit 的所有 GitHub Actions jobs；任一失败、pending 或未运行都阻止发布。
5. 合并后从 `main` 再次检查两份 README、版本与 tag 指向同一 SHA，再创建 GitHub Release。
