## 人工验收步骤

1. 在干净 checkout 运行 `npm test`、`npm run lint:markdown`、`npm pack --dry-run --json`，
   确认 47/47 通过、lint 通过、tarball 112 条目。
2. 运行 `npm pack` 生成 tarball，在隔离 HOME 中执行
   `bash tests/scripts/claude-smoke.sh`，确认 Claude Code 发现并调用 /harness。
3. 安装 Codex CLI 后运行 `bash tests/scripts/codex-smoke.sh`，确认真实调用通过。
4. 推送分支至 GitHub，确认三个 Workflow 全绿后再更新跨平台结论。
5. 确认 npm 包名与发布组织，发布后用 registry 的 `npx harness-armor` 重跑 smoke test。
6. 评估 ADR 0001 中的许可证替代方案，决定是否在后续版本切换。
