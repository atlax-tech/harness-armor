# 2026-07-10 七个 Agent Skills

## 完成内容

- 实现 `harness`、`harness-init`、`harness-build`、`harness-promotion`、`harness-update`、`harness-check`、`harness-prompt` 七个独立 Skill。
- 每个 Skill 都包含合法 frontmatter、明确触发边界、输入/输出、命令式工作流、授权门、允许与禁止修改范围、验证、失败处理和结果格式。
- 每个 Skill 均包含自身的 `references/`、`assets/`、`scripts/`，并提供可选 `agents/openai.yaml`；公共核心不依赖 OpenAI 字段。
- `harness-update` 固定为“只读计划 → 明确授权 → 有限应用”两阶段；`harness-check` 和 `harness` 永远只读。
- `harness-prompt` 明确分离 execute/test/review 三角色，禁止执行者自证通过。

## 人工验收步骤

1. 随机选择一个 `skills/*/SKILL.md`，确认 description 同时写明适用与不适用场景。
2. 检查 `harness-update`，确认未授权阶段禁止任何 Manifest、时间戳或日志写入。
3. 检查 `harness-prompt/assets/`，确认执行、测试、审查模板的职责和判定互相独立。
4. 在源码布局执行任一 `skills/*/scripts/*.py --help`，确认能够定位唯一共享运行时。
